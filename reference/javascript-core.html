Quick Reference 01

JavaScript Core

値を作り、名前を付け、条件で分け、関数へ渡す。まずは「今どの式が評価され、どの値になったか」を追う。

よく使う構文

値・変数・分岐

const price = 800;
let count = 2;
const total = price * count;

if (total >= 1500) {
  console.log("送料無料");
} else {
  console.log("送料あり");
}

配列・オブジェクト・関数

const user = { name: "Aki", active: true };
const scores = [72, 88, 95];

function average(values) {
  const sum = values.reduce((a, b) => a + b, 0);
  return sum / values.length;
}

const result = average(scores);

仕組み：式から結果まで

  1. ソースを解析
  2. 式を順に評価
  3. 値を束縛
  4. 関数を呼ぶ
  5. 値を返す
追跡の軸: 変数は箱そのものではなく、値への名前。関数呼び出しでは引数の式を評価し、その結果を仮引数へ渡し、return の値を呼び出し元へ戻す。オブジェクトは参照値なので、同じオブジェクトを指す複数の名前から変更が見える。

ありがちな誤解

  • const なら中身も不変？ 再代入できないだけ。オブジェクトのプロパティは変更できる。
  • == と === は同じ？ == は型変換を伴う。通常は型も比較する === を基準にする。
  • async は別スレッド？ そうとは限らない。Promise とイベントループによって、完了後の処理を後のタイミングへ予約する。

自己テスト

  1. const item = { n: 1 }; item.n = 2; は成功するか。理由も説明する。
  2. average([2, 4, 6]) の評価を、引数・仮引数・戻り値の順で説明する。
  3. "5" + 1 と "5" - 1 の結果を予想し、MDN で型変換の根拠を探す。
