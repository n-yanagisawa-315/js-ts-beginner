Quick Reference 04

SQL

読む、絞る、並べる、集計する、結ぶ、更新する。変更系SQLは対象行をSELECTで確かめてから実行する。

検索と集計

SELECT

SELECT id, customer, total
FROM orders
WHERE status = 'unpaid'
ORDER BY total DESC
LIMIT 10;

GROUP BY

SELECT status,
  COUNT(*) AS count,
  SUM(total) AS amount
FROM orders
GROUP BY status;

JOINと更新

JOIN

SELECT o.id, c.name
FROM orders AS o
JOIN customers AS c
  ON c.id = o.customer_id;

安全な更新

BEGIN;
UPDATE orders
SET status = 'paid'
WHERE id = 3;
COMMIT;
確認の軸: FROMで表、WHEREで行、SELECTで列、ORDER BYで順番を決める。NULLは= NULLではなくIS NULLで調べる。
