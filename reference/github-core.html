Quick Reference 05

Git & GitHub

作業中、ステージ、コミット、共有先を分けて考える。変更を確認してから記録し、branchからPull Requestを作る。

毎日の基本

記録

git status
git diff
git add src/orders.js
git diff --staged
git commit -m "注文表示を追加"

branchと共有

git switch -c feature/order-filter
git push -u origin feature/order-filter
gh pr create --base main
gh pr status

状態の流れ

  1. ファイルを変更
  2. git add
  3. git commit
  4. git push
  5. Pull Request
確認の軸: git statusで現在地を確認する。Gitは手元の履歴管理、GitHubは共有・レビュー・自動化を担う。
