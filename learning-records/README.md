# Learning Records

このディレクトリには、ユーザーが実証した非自明な理解だけを `0001-<dash-case-name>.md` の形式で記録する。教材を表示した、説明を読んだ、問題を開いたという事実だけで「学習済み」と捏造しない。

## attempt 履歴から昇格する条件

アプリの attempt 履歴は観測材料であり、そのまま学習記録ではない。次の証拠を確認できた場合にだけ、要点を短い学習記録へ昇格する。

- 初見または時間を空けた課題で、正答の理由を自分の言葉で説明できた
- コードを修正し、実行結果またはテスト結果で検証できた
- 同じ概念を表面の異なる問題へ適用できた
- 誤答後に、どの前提が誤りだったかを説明し、再挑戦で修正できた
- ユーザーが既有知識とその深さを明示した

単発の正答、選択肢の推測、答えを見た直後の再入力、未完了の入力、単なる閲覧は昇格させない。attempt の回数や点数だけで理解を断定せず、回答内容、説明、修正差分、検証結果を合わせて判断する。

## 記録の作り方

1. 既存レコードの最大番号に 1 を足す。
2. `LEARNING-RECORD-FORMAT.md` の方針どおり、題名と 1〜3 文を基本にする。
3. 何を理解したかと、それが次の教材難易度をどう変えるかを書く。
4. 後から誤りや理解の深化が判明したら削除せず、旧記録を `Status: superseded by LR-NNNN` として新記録へつなぐ。

現時点では学習の実証がないため、番号付きレコードは作成しない。
